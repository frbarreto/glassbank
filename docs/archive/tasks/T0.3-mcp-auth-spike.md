# T0.3 mcp-auth-spike

Status: done (spike delivered and wired into `src/server.ts` by the integrator at T0.5; verified against `node dist/server.js` and the shipped container). See docs/blocks/mcp.md and docs/blocks/auth.md for the gaps L4/L5 inherit.
Block: mcp + auth            Phase: 0            Owner: (unclaimed)

Goal: a hello-MCP server with the mock authorization server on one origin that MCP Inspector can complete OAuth against and call `get_current_user` on, proving the exact shapes claude.ai needs before anything else is built.

Inputs: `docs/ARCHITECTURE.md` section 5 (sequence and rules), `docs/TOOL_CATALOG.md` sections 1-2, `docs/DEPLOYMENT.md` section 3, `src/contracts/auth.ts` (may start with local stubs if T0.2 is not merged); A-02, A-03, A-06, A-11, A-12, A-13, A-37, A-43, ADR-2, ADR-3, ADR-4, ADR-8, ADR-13, ADR-16.

Paths you may edit: `src/mcp/**`, `src/auth/**`, `docs/blocks/mcp.md`, `docs/blocks/auth.md`, `docs/observations/claude-ai.md` (spike findings section), `docs/DEPENDENCIES.md` (lines for SDK and `jose`).

Paths that are read-only: `src/contracts/**`, `src/app.ts` (request the mount lines in your output), `package.json`, every other block.

Deliverables:
- `/mcp` via stateless `StreamableHTTPServerTransport` (`sessionIdGenerator: undefined`, `enableJsonResponse: true`), GET/DELETE -> 405, empty `prompts` and `resources` capabilities answered with empty lists.
- Bearer gate before the SDK: 401 + `WWW-Authenticate: Bearer resource_metadata=..., scope=...` + body `{"detail":"No access token provided"}`; parses `method` / `params.name` and answers 403 `insufficient_scope` with every still-needed scope and `resource_metadata` for a `tools/call` lacking its scope.
- Tools registered from the raw published JSON schema (SDK auto-validation bypassed); `get_current_user` with `rationale`; a call without `rationale` reaches the handler.
- PRM at root and `/mcp`, RFC 8414 metadata, issuer/`resource`/`aud` derived from the request `Host` when in `PUBLIC_HOSTS`.
- `mcpAuthRouter` mounted with `rateLimit: false` in `authorizationOptions`, `tokenOptions` and `clientRegistrationOptions`; a provider whose `authorize()` redirects to a minimal persona picker (three personas, auto-consent) carrying a signed `txn` JWT; the `login_id` cookie set on the picker.
- DCR public clients in a bounded LRU; PKCE S256; `resource` audience; signed JWT codes/access/refresh with `jti` and `typ`; consumed-code and rotated-refresh sets; callback allowlist with port-agnostic loopback; `iss` in the redirect.
- Minimal app-level per-IP limits on `/register`, `/authorize`, `/token` (knob names from `docs/DEPLOYMENT.md` section 3).
- Per-request logging of `MCP-Protocol-Version`, `initialize.params.protocolVersion`, `clientInfo`, `Origin`, `User-Agent` (to stdout for the spike; `xray` events from L4).
- A time-boxed (half a day) trial of `@modelcontextprotocol/server` 2.0.0 + `@modelcontextprotocol/express` 2.0.0 + `@modelcontextprotocol/server-legacy/auth` 2.0.0 behind the same `createTransport(deps)` interface, with the result written to `docs/observations/claude-ai.md`.

Events owned / emitted: `auth.*`, `http.*`, `session.*`, `catalog.*`, `tool.*`, `protocol.*` (stdout in the spike; full emitter wiring in L4/L5).

Assumptions and decisions touched: A-02, A-03, A-06, A-11, A-12, A-13, A-37, A-43, ADR-2, ADR-3, ADR-4, ADR-8, ADR-13, ADR-16.

Definition of done: MCP Inspector (`npx @modelcontextprotocol/inspector --server-url http://localhost:8080/mcp --transport http`) completes OAuth and calls `get_current_user`; a replayed code and a replayed refresh token get `invalid_grant`; a code presented as a bearer gets 401; the 403 challenge shape is produced for a `tools/call` on a scope the grant lacks; both block docs updated; v2 trial recorded.

How to verify: `npm run dev`, then the Inspector command above and `curl` checks from `docs/DEPLOYMENT.md` section 1.3 against `localhost:8080`.

Forbidden: no session map or `Mcp-Session-Id`; no CIMD advertisement; no long-client-id experiment (dropped, A-12); no SQL; no edits to `src/contracts`.
