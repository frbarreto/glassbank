## T0.1 result (2026-09-08)

Verified locally on macOS/arm64, Node v23.10.0, npm 10.9.2, Docker Desktop 27.4.0:
`npm ci`, `npm run check` (21 tests), `npm run build` + `node dist/server.js` answering
`/healthz` with 200, and `docker build -f infra/Dockerfile .` followed by a container run that
answers `/healthz`, runs as uid 1000 and exits 0 on SIGTERM in 0.13 s.

**A-18 validated.** `better-sqlite3` 13.0.3 installs from prebuilt binaries and runs on Node 23.10
(Mac) and inside `node:22-slim` (Node v22.23.2); Express 5.2.1 and zod 4.5.4 (inside the SDK peer
range `^3.25 || ^4.0`) install and build cleanly.

**A-39 partly validated, amendment needed.** `node scripts/smoke-worker-sqlite.mjs` (exit code 1)
measures five things:
1. a `:memory:` database loads and runs inside a `worker_threads` worker - PASS;
2. the main event loop keeps ticking while a worker burns CPU inside SQLite - PASS (18 timer ticks
   in 400 ms);
3. `worker.terminate()` frees a worker stuck in `SELECT count(*)` over an unbounded
   `WITH RECURSIVE` - **FAIL**: the thread stays alive past a 2000 ms budget and the process itself
   cannot exit either (SIGKILL required);
4. `worker.terminate()` frees a worker consuming the same recursion with `.iterate()` - PASS (10 ms);
5. SIGKILL frees an equivalent out-of-process runner - PASS (2 ms).

The boundary is whether SQLite returns to JavaScript: V8 can only act on a termination request at a
JS boundary, and `better-sqlite3` 13.0.3 exposes no `sqlite3_interrupt` and no progress handler
(its prototype is `prepare transaction pragma explain backup serialize function aggregate table
loadExtension exec close defaultSafeIntegers unsafeMode`).

Consequences for `etl` (ADR-9) and for CLAUDE.md invariants 8 and 12 are handed to the integrator in
this task's output, not applied here: T0.1 owns neither `docs/ASSUMPTIONS.md`,
`docs/contracts/CHANGES.md` nor `docs/observations/claude-ai.md`, so the A-39 amendment and the
`docs/contracts/CHANGES.md` entry are the integrator's to write. Re-run the measurement any time
with `node scripts/smoke-worker-sqlite.mjs` (or `npx tsx scripts/check-worker-sqlite.ts`).
